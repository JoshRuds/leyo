# Contributing to Leyo

Thanks for helping improve Leyo. This project is still evolving, so the most useful contributions are small, well-explained changes that keep the compiler, bytecode format, VM, and docs in sync.

## Quick Start

**Fork** the repository on [GitHub](https://github.com/leyo-lang/leyo) and **clone** to your local machine. 

Run `make` to build the leyo executable. 

## Issues

When making and issue on GitHub please include the following details:

The result of:

```bash
leyo -D
```
